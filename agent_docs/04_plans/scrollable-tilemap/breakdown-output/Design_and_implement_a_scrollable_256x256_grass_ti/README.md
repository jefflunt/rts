# Design and implement a scrollable 256x256 grass tilemap client/server architecture in Go. Build an authoritative server that streams the map over TCP, a client using Ebitengine with viewport culling and arrow/mouse-edge camera panning, and a single CLI entry point supporting server, client, and local (in-memory) execution modes.

This project aims to build a high-performance, 256x256 coordinate-based tilemap game using a client/server architecture in Go. The server is responsible for generating the map (all grass tiles) and running a TCP listener to stream map data. The client connects over TCP, receives the map, and uses Ebitengine to render it inside a 1024x768 window. To ensure smooth performance, the client implements dynamic camera bounding-box culling, ensuring only tiles within the viewport are rendered. The camera supports smooth navigation through both arrow keys and mouse-edge panning. Everything is packed into a single binary with CLI modes for server, client, and local (which runs both in separate goroutines).
