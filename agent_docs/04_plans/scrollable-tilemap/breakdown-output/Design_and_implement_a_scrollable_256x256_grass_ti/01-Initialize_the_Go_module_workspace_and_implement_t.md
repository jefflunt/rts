# Initialize the Go module workspace and implement the internal domain logic for the 256x256 grass tilemap, including the core tile definitions, map representation, and coordinate translation helper functions.

This task involves initializing the Go module and establishing the directory structure. In the internal/ package, we define the foundational domain models for the 256x256 tilemap. This includes tile structures (e.g., grass variants), the core Map representation (a 256x256 grid structure), and coordinate math helpers to translate between 2D continuous space and grid cell space (e.g., tile index to world position and vice-versa). Defining these cleanly ensures that downstream components, such as the TCP server serialization and the Ebitengine client rendering/viewports, have a solid, type-safe data model to build upon.
