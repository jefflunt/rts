# Implement the input processing system in the client to capture keyboard arrow keys and detect mouse cursor position within the scroll margin for edge-scrolling, updating the camera coordinates smoothly while clamping them strictly within the boundaries of the 256x256 tilemap.

This task involves implementing the input processing logic within the Ebitengine-based game client. The system must monitor two primary types of input for panning the camera: keyboard arrow keys and the mouse pointer position. For keyboard input, the system must detect when arrow keys (Up, Down, Left, Right) are pressed and adjust the camera's world coordinates accordingly based on a configurable scroll speed. For mouse-edge panning, the system needs to detect if the cursor's screen position lies within a specified scroll margin (e.g., 15 pixels) of any window border. If it does, the camera should pan in the corresponding direction.

Crucially, the input processing system must interact with the client camera's boundary constraints. Panning must not allow the camera's viewport to slide outside the valid world boundaries of the 256x256 tilemap (e.g., between world coordinates 0, 0 and the max map scroll limits). This ensures a smooth, bounded, and responsive navigation experience. All coordinate movements should be processed relative to the frame delta time to maintain uniform scroll speed independent of the framerate.
